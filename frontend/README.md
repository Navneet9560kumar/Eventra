# Eventra Frontend

A beautiful, modern, and colorful event management platform frontend built with **React**, **Next.js**, **JavaScript**, and **Tailwind CSS**.

## 🎨 Features

✨ **Modern Design**: Sleek glassmorphic UI with stunning gradients
🎯 **Responsive**: Fully responsive across all devices
⚡ **Fast**: Optimized with Next.js for lightning-fast performance
🎨 **Colorful**: Beautiful gradient color scheme with purple, pink, and cyan accents
♿ **Accessible**: Built with accessibility best practices

## 📦 Tech Stack

- **React** - UI library
- **Next.js** - React framework with server-side rendering
- **JavaScript** - Language
- **Tailwind CSS** - Utility-first CSS framework
- **JSX** - React's templating language

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

```bash
# Navigate to the frontend directory
cd frontend

# Install dependencies
npm install
```

### Development

```bash
# Start the development server
npm run dev
```

Visit `http://localhost:3000` to see the application.

### Build

```bash
# Build for production
npm run build

# Start production server
npm start
```

## 🌈 Styling Approach

The frontend uses:
- **Tailwind CSS** for utility classes
- **Gradients** for modern, colorful design
- **Glass morphism** effects for depth
- **Custom animations** for smooth transitions
- **CSS variables** for theme consistency

## 💡 Key Files

- `styles/globals.css` - Global styles, animations, and gradients
- `tailwind.config.js` - Color scheme and custom extensions
- `pages/_app.jsx` - Application wrapper
- `components/` - React components
